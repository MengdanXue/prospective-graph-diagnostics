## 1. LODO 为什么使遗憾从 7.46 降到 2.41？Roman-empire 的约 89% 指什么？

原 Combined 在完整输入和 MLP 回退下，实际选择规则是：训练标签同配性 `h1 ≥ 0.55` 时选择 graph，否则选择 MLP。低于阈值的几个数据集恰好有较大的 graph 优势，因而产生较大遗憾。

LODO（留一数据集交叉评价）逐次留出一个数据集，用其余十个数据集选择同配性阈值，再评价留出集。阈值目标是最小化十个训练数据集等权平均遗憾；这些数据集已选择模型的测试结果被明确用作元训练目标。留出集不参与自身阈值选择。网格包含常选 graph 和常选 MLP，最优值并列时取最小阈值。

在完整 graph 组合下，**11 折中有 10 折选择阈值 `-1`，即 always-graph**。这避开了原阈值在许多低同配性数据集上的错误排除。仅留出 Roman-empire 时选到 `0.11`；Roman-empire 的十个单位均低于此阈值，仍选择 MLP，因此保留该数据集的平均遗憾 23.65655 个百分点。

现有结果的分解为：

| 核算项 | 数值 |
|---|---:|
| 原冻结 Combined 的全组合平均遗憾 | 7.45719 个百分点 |
| LODO 校准后的全组合平均遗憾 | 2.40640 个百分点 |
| always-graph 的全组合平均遗憾 | 0.25581 个百分点 |
| Roman-empire 对 LODO 等权平均的贡献：`23.65655 / 11` | 2.15060 个百分点 |
| Roman-empire 占全部 LODO 遗憾：`23.65655 / (11 × 2.40640)` | **89.37%** |

由于其他十折与 always-graph 的动作一致，而 always-graph 在 Roman-empire 上的遗憾为零，所以还有一个直接核对式：`2.40640 ≈ 0.25581 + 2.15060`。这里的 89.37% 是 Roman-empire 占**校准后全部遗憾**的比例；若只看 LODO 比 always-graph 多出的遗憾，则在这些记录中全部来自这一折。

这说明阈值校准大幅减轻了原规则的损失，却未在完整组合中优于 always-graph；它也准确定位了一次留出数据集上的转移失败。`-1` 是最小阈值并列处理的结果，不能由此断言训练数据完全不含可用诊断信息。LODO 是在原结果已知后设计的控制，训练折重叠、数据集数量有限，因此它没有把论文升级为对独立新数据集的确认性验证。

依据：[portfolio_robustness.json](../results/diagnostic/route_a_prospective_v2/analysis/portfolio_robustness.json) 的 `calibrated_threshold.full`；[equal_budget_sensitivity.json](../results/diagnostic/route_a_prospective_v2/analysis/equal_budget_sensitivity.json) 的 `full_portfolio`；[正文阈值控制](../sections_tmlr/04a_equal_budget_sensitivity.tex)。

## 2. 为什么不能说“简单结构诊断普遍失败”？

原规则的失败限定于给定模型、阈值、训练协议和数据集。现有记录本身包含相反方向的例子：

| graph 候选组合 | 冻结 Combined 遗憾 | LODO 校准遗憾 | always-graph 遗憾 |
|---|---:|---:|---:|
| GCN | 1.74 | 1.58 | 5.29 |
| GAT | 2.08 | 1.53 | 6.35 |
| GPR-GNN | 1.50 | 0.81 | 0.89 |
| 完整六架构组合 | 7.46 | 2.41 | 0.26 |

各行单位均为百分点，并使用该行自身的 graph/MLP oracle。GCN、GAT 下，冻结规则和校准规则的描述性平均遗憾都低于 always-graph；GPR-GNN 下，冻结规则较差，校准后则略低于 always-graph。这些例子同时限制了“所有候选组合都失败”和“任何同配性阈值都无用”两种说法。

有利结果也不能被放大：针对冻结规则，63 个非空组合中只有 GCN、GAT 及其二者组合优于 always-graph；同时排除 Cornell 和 Wisconsin 后，这些优势全部消失。63 个重叠组合不是 63 次独立验证。本文没有覆盖代表性的全部已发表诊断、非单调规则或学习型选择器，LODO 也没有建立它们在未见数据集上的普遍失败。

可由作者采用的中心表述是：**所评估规则在冻结协议的完整模型组合下没有展示增量价值；后验比较表明，其相对 always-graph 的遗憾优劣随候选组合变化，并对数据集组成敏感。** 这里报告描述性差异，不附加新的确认性显著性结论。

依据：[阈值与组合结果](../results/diagnostic/route_a_prospective_v2/analysis/portfolio_robustness.json)、[单架构结果](../results/diagnostic/route_a_prospective_v2/analysis/equal_budget_sensitivity.json)及[主张映射 D5–D7](claim_evidence_map.md)。

## 3. Roman-empire 的 MLP 从 16.71% 到 66.19% 为什么重要？

在单独进行的两数据集配对预处理敏感性实验中，Roman-empire 的 MLP 测试准确率由 NormalizeFeatures 条件的 **16.71%** 提高到 raw 条件的 **66.19%**，增加 **49.48 个百分点**。这一变化足以实质影响 graph 与 feature-only 的比较，说明很低的 MLP 结果不能直接被当作“节点特征本身没有预测信息”的证据。

同一配对实验也重新训练了 graph 候选组合：其准确率由 **42.16%** 提高到 **80.96%**，graph–MLP 差距从 **25.45** 缩小到 **14.77** 个百分点。两个条件下 Roman-empire 的十个种子仍全部以 graph 为实用边际定义的目标，Combined 仍选择 MLP。因此，预处理改变了已记录损失的大小，却未逆转这一数据集上的决策方向。

上述四个准确率均来自同一次配对敏感性比较，不能把新 raw MLP 与旧冻结 graph 结果拼接。它们也不是对原始 770 条记录的整体替换。后续仅用训练/验证数据的输入参数化诊断及重复性审计帮助解释优化问题，但没有提供完整 11 数据集在改进基线下的新测试遗憾，也没有认证所有历史训练均可重复。

作者需要接受的边界是：**本文测量的是具体训练方案下的模型比较；大幅改善的 MLP 基线限制了把原 graph–MLP 差距解释为边结构内在价值的程度。** 如实披露这些局限是必要的，但披露本身不能代替尚未获得的全基准稳健性证据。

依据：[preprocessing_sensitivity.json](../results/diagnostic/route_a_prospective_v2/analysis/preprocessing_sensitivity.json) 的 `datasets.Roman-empire`；[训练讨论](../sections_tmlr/07_discussion.tex)；[主张映射 P1–P6](claim_evidence_map.md)。

| 现有证据支持 | 现有证据不足以证明 |

| 指定三数据集上的保度干预显示 GCN 对非度数边组织敏感；附录推导在规定代理模型下成立。 | 干预单独识别同配性的因果效应，或理论刻画训练后 GNN 的普遍选择规律。 |

| 冻结记录与协议支持核查选择、回退、遗憾和结果来源。 | 代码测试通过、记录重建或论文编译成功即意味着科学有效性、普遍重复性或录用保证。 |
