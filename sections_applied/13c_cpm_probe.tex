\section{Training-Label-Only Classifier Probe}
\label{app:cpm}

\subsection{Information Boundary and Implementation}

We adapt the Gaussian Naive Bayes (GNB) version of the Classifier-based Performance Metric of \citet{luan2023whendo}. Metric definitions, sampling, and reporting scope were fixed before the extension began. Execution repairs preserved this scientific protocol; source revisions, interrupted attempts, and resumption bindings are retained. This remains a post-hoc extension of the existing benchmark. The metric API receives only the outer-training nodes' features, aggregated features, and labels. Full topology and node features are available under the existing transductive setting. Candidate validation and test outcomes are read only after all 220 metric records have been computed.

For each dataset, seed, and input condition, let $X$ be the bound feature matrix and $P=D^{-1}(A+I)$ the row-normalized binary undirected adjacency with one self-loop per node. We compare GNB fitted on $X$ and $PX$ through 100 repeated inner splits of the outer-training labels. If more than 500 training nodes are available, each repeat samples up to $\operatorname{round}(500/C)$ nodes per observed class, exhausting smaller classes; rounding can slightly exceed the nominal cap. Otherwise it uses every outer-training node. For the inner fit, each class contributes up to $\operatorname{round}(0.6n_s/C)$ sampled nodes, with the remainder held out. This follows the author's equal-quota sampling structure; imbalanced classes can yield a fit fraction different from 60\%. Both probes use identical partitions, empirical class priors, and \texttt{GaussianNB} with \texttt{var\_smoothing}$=10^{-9}$. Fitting uses float64 values of the bound float32 features. An all-constant fit reduces to the empirical-prior prediction. Dataset/split-derived seeds fix the partitions across N and CS.


\paragraph{Realized sampling and class support.}
Replaying all 100 partitions for every dataset and seed reproduces the hashes and sizes of all 220 condition records without fitting a classifier. Table~\ref{tab:cpm_support} reports actual counts. Cornell fits 58/108 sampled nodes (53.7\%); Wisconsin fits 72/149 (48.3\%). Their class-ordered fit/holdout vectors are $(13,9,13,13,10)/(9,0,5,36,0)$ and $(6,18,18,18,12)/(0,24,52,1,0)$, respectively, identical across seeds and repeats. Thus two classes in each dataset have no inner-held-out examples. The holdout accuracy estimates performance on the resulting class distribution, not on every original class. These counts are an implementation audit of the retained adapter; no sampling rule or score was changed. The same WebKB result is reproduced from public raw files and bound labels.

Writing $x_r$ and $g_r$ for the two inner-holdout accuracies, we retain the author's implementation rule: let $p$ be the two-sided Welch statistic's tail probability and $w$ the fraction of repeats with $g_r>x_r$; define $s=p/2$ for $w\leq 1/2$ and $s=1-p/2$ otherwise. Equal constant accuracy sequences receive $s=1/2$; unequal constant sequences receive the corresponding directional endpoint. Because repeats reuse nodes and the direction uses win frequency, we treat $s$ as a descriptive score. We also retain the mean probe gap $\bar g-\bar x$.

We evaluate three fixed policies: graph for $s\geq0.5$; graph for $s>0.95$, MLP for $s<0.05$, otherwise abstain with MLP fallback; and graph for a nonnegative mean probe gap. Each remaining fixed decision chooses MLP. Separately, both scores receive the same observed-midpoint/constant-action LODO calibration used in Section~\ref{sec:matched_audit}. The held-out dataset contributes neither scores nor outcomes to cutoff fitting. Other datasets' selected-model test outcomes remain explicit meta-training targets. All four portfolios, both inputs, and both MLP budgets are retained, with no new superiority test.

Our adaptation restricts label access, specifies the bound input maps and graph operator, changes the random-number generator, and declares degenerate-score handling. The pinned author CLI reloads raw adjacency and features in its CPM branch, so we specify the operator directly rather than infer it from preceding preprocessing code. Source revisions and these adaptations are retained with the results. The experiment evaluates this GNB probe and operator.

\subsection{An Input-Invariance Check}

For a row-stochastic $P$, a nonzero common scalar $a$, and a fixed feature shift $b$, the affine map $T(X)=a(X-\mathbf{1}b^\top)$ satisfies
\begin{equation}
P T(X)=a(PX-\mathbf{1}b^\top).
\end{equation}
In any fixed inner fit, each GNB class mean transforms to $a(\mu_c-b)$, each class variance to $a^2v_c$, and its global variance floor to $a^2\epsilon$. Class priors are unchanged. Every class log likelihood therefore acquires the same constant $-d\log|a|$, preserving predictions, the two accuracy sequences, their mean difference, and $s$ in exact arithmetic. Deterministic class ties and the constant-feature fallback preserve the same conclusion. This argument uses a common scale; arbitrary feature-wise scales need not preserve the global variance floor. It also depends on $P\mathbf{1}=\mathbf{1}$, which symmetric GCN normalization generally does not satisfy.

N and CS have this affine relationship within each outer split. In exact arithmetic, this transformation is invertible and preserves the information in the features; it can nevertheless change finite-budget optimization of the trained candidates. A fixed policy using either probe score alone therefore cannot respond to downstream training effects of this transformation in exact arithmetic. Calibrated policies can still change because their other-dataset outcome targets change. The numerical comparison below checks this Gaussian-likelihood invariance on the actual finite-precision input maps.

The finite-precision check finds identical paired accuracy sequences on 41 of 110 dataset--seed pairs. Across all pairs, the maximum absolute score difference is $2.78\times10^{-4}$; the largest difference in the mean probe gap is 0.485 accuracy percentage points. Despite these numerical differences, all three fixed policies produce identical decisions across N and CS: graph on 60 units and MLP on 50, with full coverage for the two-cutoff policy. The retained repeated accuracies and pairwise differences document this stability.

\subsection{Score Resolution}

Under each input condition, 30 of 110 scores equal floating-point 1.0, none equals zero, and 81 distinct values remain. All ten Cora, CiteSeer, and Chameleon scores are 1.0. The map $1-p/2$ rounds sufficiently small upper-direction tail probabilities to one, compressing different probe gaps into a common value. This numerical property restricts the observed-midpoint candidates available to CPM-L. Gap-L retains the mean accuracy difference and therefore a different ordering and resolution. Table~\ref{tab:cpm_resolution} reports the stored score ranges and exact endpoint counts. These summaries characterize the score used by the declared policies; they do not isolate the contribution of compression from that of the downstream decision target.

\subsection{Execution and Retained Evidence}

The extension contains 22,000 paired inner-holdout comparisons. Included cell timings sum to 2,825.032 seconds of wall time in the author's single-thread CPU execution. This sum covers the 220 retained cells; it excludes preparation, packaging, and excluded attempts, and is not an end-to-end cost comparison against neural training. An initial implementation repair separated the outer seed index from the probe's resampling seed; all 25 partial records from that attempt were excluded. A later worker wall cap retained 218 valid cells. Hash-bound resumption validated that prefix and computed the last two cells, with 215.437 seconds of worker wall time for the resumed pass. The records preserve both execution revisions and all interruption charges. No neural candidate was retrained or checkpoint reevaluated in this extension.

\subsection{Independent Reader Reproduction}
\label{sec:reader_reproduction}

The flat reader exposes four commands: \texttt{acquire}, \texttt{probe}, \texttt{score}, and \texttt{train}. All paths are explicit, and the scientific commands run without the author's controller, ledger, Git checkout, or CI receipts. Raw-file checksums identify the public upstream inputs. Array hashes include dtype, shape, and C-order bytes, separating scientific data identity from PyG's processed-file serialization. The input reconstruction regenerates canonical edges and the declared stratified split, then fits the same training-feature centering and common scale. A failed file, tensor, split, or feature binding stops the reconstruction.

For a preselected Cora, seed~0 demonstration, raw files were acquired into a new reader directory. Raw features, labels, canonical edges, all three partitions, the split identifier, and the two transformed feature arrays matched their bindings. The two input conditions each reproduced 100 paired inner holdouts, for 400 GNB fits in total. The complete repeated accuracies, partition hashes, scores, and mean gaps agreed with the retained records within absolute tolerance $10^{-12}$. Only after computing both probes did the reader open candidate outcomes and reconstruct their fixed-rule scores for the matching portfolio/budget cells. The probe stage took 25.344 seconds on the recorded Windows/Python~3.12 environment; this excludes acquisition and is a reproduction receipt, not a comparative efficiency result.

The independent score command reselects candidates from the 1,760 supplied model records and reconstructs every field of the original 112 CPM policy cells within $10^{-12}$. It also computes the 16 constant-MLP references and Table~\ref{tab:cpm_resolution}. The optional training command uses the published architecture implementations and grids, retains every newly fitted checkpoint, selects by validation, and evaluates the winner once on the test split. A 24-trial reader run fits all candidates afresh, including the four originally inherited trials. The Cora probe demonstration and saved-score reconstruction do not certify a full neural retraining of the benchmark. All new reader outcomes retain separate identities from the published experiments.
